
# Posting today's menu

Officers: this folder is where the café menu goes. The newest file you upload here appears on the website within a couple of minutes.

## Post the menu

1. On this page, click **Add file → Upload files** (top right of the file list).
2. Drag in today's menu, or click **choose your files**.
3. Click **Commit changes**.

That's it. You don't need to rename the file or delete yesterday's; the website always shows whichever file was uploaded most recently. To check it worked, open the **Actions** tab and wait for the green checkmark, then refresh the website.

## What to upload

- **A screenshot or photo** (PNG, JPG, WebP, or GIF, under 20 MB). It appears on the site exactly as uploaded.
- **A spreadsheet saved as CSV** (in Excel or Google Sheets: *File → Save as / Download → CSV*). It becomes a clean text menu with prices and allergens. Use these columns:

```
  Group,Item,Description,Price,Sold out
  Combos,Chicken Nuggets and Fries,"Breaded tenders, fries. Contains: Wheat, Egg",7.00,
  Sides,Cookies (2),,1.50,yes
```

- **A plain text file** with one item per line and the price at the end. Lines without a price become section headings:

```
  Combos
  Chicken Nuggets and Fries - $7.00
  Sides
  French Fries - $2.00
```

CSV or text is better when you can: screen readers can't read a screenshot, and allergen details are easier to read as text.

## Before you upload

- Crop screenshots so they don't show notifications, emails, or other tabs.
- Double-check prices and allergen notes. People with food allergies rely on them.

## Fixing a mistake

Just upload the correct file. It becomes the newest one and replaces the mistake on the site.
To remove a file entirely, click it, then the **⋯** menu → **Delete file**, and commit.

Only index.html and the newest menu file in this folder are ever published, so any other kind of file uploaded by accident won't appear on the site.
